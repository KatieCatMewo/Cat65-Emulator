# Cat65 Emulator

this is an emulator for a 6502-based computer system inspired by [Ben Eater](https://www.youtube.com/@BenEater)
that I call the "Cat65" :3c  

> [!NOTE]
> documentation for emulator, `.c65` file format and general Cat65 architecture is still in development  

> [!IMPORTANT]
> yes, claude was used in making this but don't hate me yet  
> claude was just used to look for issues and fix an issue with gradle, all the java code is still written by humans  

> [!WARNING]  
> it works on my machine but the SDK + JavaFX setup might not work immediately for you, sorry
